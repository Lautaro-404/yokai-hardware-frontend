02. Ciclo de Vida y Transacciones

Flujo de Compra Atómica & Prevención de Overselling

Visualización paso a paso de cómo el sistema procesa una orden de compra manteniendo la integridad de stock mediante límites transaccionales ACID en Spring Boot.

1 Frontend

Inicio Checkout

El cliente autenticado envía los datos de entrega y el contenido del carrito mediante un POST a `/api/pedidos` con el header `Authorization: Bearer <JWT>`.

Payload DTO Validado
2 Security

Validación JWT

`JwtAuthenticationFilter` extrae el token, verifica la firma criptográfica con la clave secreta y asegura que el usuario posea el rol `ROLE_CLIENTE`.

SecurityContextHolder OK
3 @Transactional

Bloqueo de Stock

`PedidoService` abre una transacción ACID. Valida que `stock >= cantidad`. Si hay unidades suficientes, aplica el decremento atómico. Si no, lanza `StockInsuficienteException` (Rollback total).

Prevención Overselling
4 PostgreSQL

Persistencia ACID

Se inserta el registro `Pedido` con estado `PENDIENTE` o `PAGADO`, y los ítems en `DetallePedido`. Se limpia el carrito del usuario. Commit transaccional garantizado.

Integridad Referencial OK
5 Respuesta

Confirmación 201

El servidor responde con código `201 Created` y el DTO del pedido con su ID único, número de orden y resumen financiero. El frontend muestra la pantalla de éxito.

Pedido Confirmado #ORD-

05. Propuesta de Valor & Innovación

Motor de Compatibilidad de Hardware

Algoritmo inteligente en tiempo real que valida la correspondencia técnica entre componentes seleccionados, previniendo compras incompatibles y errores de ensamblado.

01

Socket CPU ↔ Placa Madre

Validación Física de Conector

El motor compara el identificador normalizado de zócalo. Por ejemplo, un procesador AMD Ryzen 7 (Socket AM5) requiere obligatoriamente una placa madre con chipset AM5 (B650 / X670). Si no coincide, alerta de incompatibilidad crítica y deshabilita el agregado simultáneo al carrito.

cpu.socket == motherboard.socket
02

Consumo Energético (TDP)

Dimensionamiento de Fuente

Calcula el consumo total sumando el TDP estimado de CPU + GPU + margen del sistema (25% overhead). Si la fuente elegida entrega menor potencia a la recomendada en la línea de 12V, emite una advertencia de riesgo de apagados repentinos.

psu.watts >= (cpu.tdp + gpu.tdp) * 1.25
03

Dimensiones & Despeje

Compatibilidad de Gabinete

Verifica el largo de la placa de video (GPU Length en mm) contra la longitud máxima soportada por el gabinete (Case Max GPU Clearance) y la altura del disipador de CPU respecto al ancho del chasis.

gpu.length_mm <= case.max_gpu_mm
